## Updates

A lógica de vigência do valor no mês não agrega no negócio, o cliente não precisar ficar trocando o preço dos itens toda vez que o mês vira.

Hoje, a troca acontece, entre 1 ou 2 vezes por ano, isso é uma estimativa.

O que o cliente imagina:
Preço fixo, com campo onde ele informa uma referência de data para o valor ser modificado, se chegar nessa data e o preço não for modificado, o valor é mantido, e o sistema avisa que a data de referência do valor chegou, se ele quer editar o valor ou manter, editando, cliente salva a nova data, mantendo, cliente escolhe uma nova data e salva.

Histórico: sistema entende quando o valor é trocado, a partir da data da edição, determinado item tem um novo valor, mas o histórico de relatórios, nos períodos anteriores mantém o valor que estava antes de ser alterado, histórico preservado com segurança.
